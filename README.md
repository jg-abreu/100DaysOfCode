# 🚀 Desafio 100 Dias de Código

Commitando código todo dia, por 100 dias seguidos. Bora!

## Sobre o desafio
Durante 100 dias, o objetivo é estudar e/ou praticar programação todo santo dia, registrando o progresso aqui neste repositório através de commits diários.

## Regras
- Estudar ou codar todo dia (nem que seja pouco — o importante é não quebrar a sequência)
- Commit todo dia, sem furo
- Cada dia tem sua própria pasta (`dia-001`, `dia-002`, ...) com o código feito

## Padrão de commit

```
Dia 01: descrição curta do que foi feito
```
